功能一：最高分、最低分、及格人數（只用 for 和 if）

要求：

印出全班最高分。
印出全班最低分。
印出及格（60 分以上，包含 60）的人數。
不能用 max()、min()，要自己在迴圈裡用 if 比較。

範例資料：5 位同學，分數依序是 85、42、60、73、59


功能二：列出低於平均的同學（需要串列）

要求：

在輸入分數的迴圈裡，把每個分數存進串列。
算完平均後，再用一個 for 找出低於平均的同學，印出座號和分數。
最後印出低於平均的人數。
如果沒有人低於平均（例如全班同分），就印出「沒有人低於平均」。


完成檢查清單
 用範例資料 85、42、60、73、59，輸出和上面完全一樣
 輸入 1 位、分數 100，最高分和最低分都是 100
 輸入 3 位、分數都是 0，最低分是 0，及格人數是 0
 輸入 3 位、分數都是 80，顯示「沒有人低於平均」
 輸入一位剛好 60 分的同學，有算進及格人數
 功能一沒有用到 max()、min()
